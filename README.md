## Publish with GitHub Pages

1. Open the repository's **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch `main` and folder `/(root)`, then click **Save**.
5. Wait for GitHub Pages to finish publishing; the public URL will appear on the Pages settings screen.

## Responsible sharing

Review every file before publication. Do not commit passwords, API keys, access tokens, private logs, personal information, internal employer materials, or sensitive system/network details. Use only lab systems and authorized test activity.

## Accuracy

Statuses are intentionally separated: completed write-ups are marked documented, the broader SOC lab remains in progress, and authentication analysis is planned. Update these labels only when work has actually been completed.
